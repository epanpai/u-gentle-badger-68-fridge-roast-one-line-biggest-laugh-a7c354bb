## The entry

> My fridge emailed my doctor about my midnight cake, yet the app insists the milk that expired three Tuesdays ago is 'still thriving'.

A one-line roast of a smart fridge: the camera/app snitches on your midnight cake to your doctor, yet the same app confidently insists milk that expired three Tuesdays ago is "still thriving". The punch lands on the last words, and the snitch-vs-incompetent contrast dodges the stock ordering-groceries and watching-you cracks.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–200 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
